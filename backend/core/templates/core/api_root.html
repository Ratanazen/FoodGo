Authentication

JWT-based auth with access & refresh tokens. Register, login, and manage your session securely.

Restaurants & Food

Browse restaurants, categories, and food items. Filter by availability and cuisine type.

Orders & Cart

Full order lifecycle management — place orders, track status, and manage cart items.

Delivery Tracking

Real-time driver assignment and delivery tracking from pickup to doorstep.

Payments

Notifications

Push notification management for order updates, promotions, and delivery alerts.

API Endpoints

POST /api/auth/register/ Register a new user
POST /api/token/ Obtain JWT token pair
POST /api/token/refresh/ Refresh access token
GET /api/restaurants/ List all active restaurants
GET /api/food-items/ Browse available food items
GET /api/cart/ View your cart
POST /api/orders/ Place a new order
GET /api/orders/ List your orders
GET /api/notifications/ View notifications
