# FoodGo — Repository Audit & Baseline Verification

## 1. Executive Summary
This audit inspects the current state of the FoodGo codebase prior to implementing the modern UI/UX design and interactions referenced in the TikTok video ([@dailyflutterui / 7696552901430250759](https://vt.tiktok.com/ZSgL7AymR/)).
The audit verifies that all backend payment systems (Bakong KHQR, ABA PayWay, ACLEDA, COD, Wallet) and delivery QR confirmation workflows are functional and covered by tests.

---

## 2. Technical Stack Audit

### Mobile Frontend (`foodgo_flutter`)
- **Framework**: Flutter 3.x / Dart 3.x
- **State Management**: `Provider` (`CartProvider`, `OrderProvider`, `RestaurantProvider`, `AddressProvider`, `FavoritesProvider`, `NotificationProvider`, `WalletProvider`, `ThemeProvider`, `LocaleProvider`)
- **Navigation**: `GoRouter 14.2.0` with shell route, deep linking, and authentication guards
- **Networking**: `Dio 5.7.0` with token interceptor and retry queue
- **Maps**: `flutter_map 8.3.1` (OpenStreetMap / CartoDB tile layers, no paid API keys required)
- **Local Storage**: `flutter_secure_storage 11.0.0` & `shared_preferences 2.5.6`
- **QR Code**: `qr_flutter 4.1.0` (NBC EMVCo KHQR CRC-16 CCITT compliant)

### Backend API (`backend`)
- **Framework**: Django REST Framework (DRF) 3.18.3 on Django
- **Real-Time WebSockets**: Django Channels 4.3.2 with Redis channel layer and JWT authentication
- **Authentication**: SimpleJWT with access/refresh tokens, token blacklisting, and Google OAuth
- **Database**: SQLite (local testing) / PostgreSQL (production)

## 5. Risk Analysis & Guardrails

1. **Payment Flow Breakage**: Replacing the checkout or cart flow could break KHQR generation.
   - *Mitigation*: The cart, checkout, payment modal, and QR generation remain decoupled from the home UI.
2. **WebSocket Driver GPS Breakage**: Modifying the map screen could disrupt live driver coordinates.
   - *Mitigation*: `LiveTrackingScreen` retains the exact `OrderTrackingConsumer` WebSocket connection and fallback polling.
3. **Theme Incompatibility**: The video has a vibrant green and light background, whereas FoodGo previously featured dark glassmorphism.
   - *Mitigation*: Support both themes cleanly. In light mode, render the crisp lush green delivery design; in dark mode, preserve glass surfaces with green brand accents.
